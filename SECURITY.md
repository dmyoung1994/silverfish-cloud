# Security

Please do not open a public issue for a suspected vulnerability.

Use the repository's **Security → Report a vulnerability** flow to send a
private GitHub security advisory. Include the affected version, reproduction
steps, impact, and any suggested mitigation. Reports will be acknowledged as
soon as practical.

Silverfish is a preview. Hosts should invite only trusted collaborators, keep
secrets outside agent-readable workspaces, and deploy self-hosted relays behind
TLS with appropriate edge rate limits and an origin allowlist.
